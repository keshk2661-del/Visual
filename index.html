Установка

Четыре шага

Нужен Minecraft Java 1.21.11 с загрузчиком Fabric.

  1. Fabric LoaderУстанови Fabric для версии 1.21.11 через установщик с fabricmc.net.
  2. Fabric APIСкачай Fabric API для 1.21.11 и положи в папку mods.
  3. МодПоложи fa1roxx-visuals.jar туда же, в mods.
  4. ЗапускЗапусти игру с профилем Fabric и нажми Правый Shift в мире.

Вопросы

Частые вопросы

На каких версиях работает?

Только Minecraft Java 1.21.11 с Fabric Loader и Fabric API. На другие версии и на Forge мод не встанет.

Как открыть меню?

Правый Shift в мире или кнопка «fa1roxx visuals» в меню паузы (Esc). Клавишу можно сменить в Управлении.

Можно ли играть на серверах?

Мод клиентский, на сервер ставить ничего не нужно. Правила у серверов разные, и некоторые запрещают fullbright или растяг. Перед игрой проверь правила своего сервера.

Зачем оффлайн-аккаунты?

Чтобы быстро менять ник на серверах без лицензии. На лицензионных серверах оффлайн-ник не пустят.

Шлейф и шляпу не видно

Они видны только от третьего лица. Нажми F5.

Что делать, если что-то не работает?

В главном меню слева сверху мод пишет, всё ли в порядке. Если там ошибки, пришли файл config/fa1roxxvisuals-report.txt в поддержку в Discord.
